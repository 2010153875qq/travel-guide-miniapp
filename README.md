# 趣游旅行攻略微信小程序

这是一个零后端、本地保存的原生微信小程序 MVP，适合在微信开发者工具中导入预览。

## 已包含

- 6 个目的地：长沙、张家界、成都、重庆、西安、厦门
- 首页搜索与目的地筛选
- 目的地详情页、微信地图打开位置
- 收藏与取消收藏，本地持久化保存
- 旅行天数与预算输入，生成并保存本地参考行程

## 导入

1. 在微信开发者工具选择“导入项目”。
2. 目录选择本仓库根目录。
3. AppID 填写你的小程序 AppID；当前项目配置为 `wxb70e4adf8d466015`。
4. 先使用模拟器预览，再用“真机预览”检查地图、收藏和行程保存。

项目不含服务器、登录、第三方地图密钥、实时天气或真实 AI 接口；地图使用微信 `wx.openLocation`，示例数据请在发布前自行核实。

## 云端上传

仓库的 GitHub Actions 使用 `miniprogram-ci` 上传开发版。上传私钥只放在 GitHub 仓库 Settings → Secrets and variables → Actions → `WECHAT_UPLOAD_KEY`，不要提交到代码。

如果出现 `20002 generate local signature fail`，通常是私钥与 AppID 不匹配、私钥已失效或小程序后台没有开启该 IP 的上传权限。请在微信公众平台重新下载与当前 AppID 对应的上传密钥，完整粘贴到 `WECHAT_UPLOAD_KEY`，然后重新运行 Actions；旧密钥不要继续使用。
